# AOE2LinuxAI

Linux + LM Studio port of [dobosmarton/aoe2-agent](https://github.com/dobosmarton/aoe2-agent).

An LLM agent that plays Age of Empires II: Definitive Edition via YOLO/OCR perception and Linux-native input (`xdotool` / `ydotool`). Local models run through LM Studio (`AOE2_LLM_WIRE=lmstudio`).

Full source is being uploaded in follow-up commits.
